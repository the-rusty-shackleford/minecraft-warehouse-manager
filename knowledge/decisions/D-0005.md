# D-0005 — EMI counts the building's containers through a first-placed recipe handler

Accepted 2026-09-23.

Rusty, at a crafting table in the warehouse on pack 1.56.0: "clicking the book icon and
nothing shows up; it is clearly not pulling from my pooled chest inventories". The server had
done its part (its log: "opened a table in the building at -1570, 68, -355: sending 66
kinds") and the vanilla recipe book counts the tally (D-0004), verified in a booth that ran
without EMI. The pack ships EMI, and EMI's `RecipeBookWidgetMixin` cancels the vanilla book's
toggle: with its default recipe book action, the button toggles EMI's own craftables view.
EMI decides what a screen can craft from by asking the *first* recipe handler registered for
the screen's menu type, its own `CraftingRecipeHandler` for the crafting table, which reads
the menu's slots. The pooled tally reached a book the player could never open.

Accepted: an EMI plugin (`integration/emi/WarehouseEmiPlugin`, loaded only when EMI is
present) registers `PooledCraftingHandler` for the vanilla crafting table and moves it to the
front of EMI's handler list (`EmiRecipeFiller.handlers`, a public static map; the registry API
only appends). The handler reports the input slots plus the tally the server sent for that
container id, so EMI's craftables view and fill buttons count the building; its fill for a
managed table sends the vanilla recipe-placement packet, which the server answers by drawing
the shortfall from the containers before placing (D-0004's path, unchanged). For a table the
server did not report as managed, the handler behaves exactly like EMI's own.

Rejected: a mixin into EMI's `EmiPlayerInventory` (private merge logic, internal timing);
telling players to set EMI's recipe book action to Default (a per-client setting the pack
cannot ship, and EMI's craftables view is the better one). The public static list is the one
non-API touch; a future EMI that orders handlers differently shows up in the booth, which now
runs with EMI and asserts the handler stands first and that EMI's fill draws from the chests.

Lesson: a booth must run with the pack's client mods that touch the same UI. This feature was
verified without EMI and shipped broken for every player.
